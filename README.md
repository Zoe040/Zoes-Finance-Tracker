# Zoes Finanzen

Persönlicher Finanz-Überblick als Web-App: VR-Bank-CSV importieren, Budgets, Verträge und Abos, Spartöpfe, Prognose.

**Alle Daten bleiben auf dem Gerät.** Die App lädt nichts hoch. In diesem Repo liegt nur die App selbst.

Installieren auf dem iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
